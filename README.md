# PINN پارامتریک برای موقعیت اولیهٔ دو ذره از چهار ذره

این نسخه بر پایهٔ کد ارسالی شما نوشته شده است. ذرات **۱ و ۲** موقعیت اولیهٔ متغیر دارند؛ ذرات ۳ و ۴ به‌ترتیب از `(0.19, 0.26)` و `(0.13, 0.26)` شروع می‌کنند. هندسهٔ گرفتگی، Re، St، بارگذاری جرمی، شعاع ذرات و ضرایب نیرو در طول آموزش ثابت‌اند. فایل PDF فقط به‌عنوان سابقهٔ علمی گفتگو بررسی شد؛ ادعاها یا دستورهای داخل آن معیار تأیید نتایج جدید نیستند.

## ورودی شبکه‌ها و دامنهٔ آموزش

| شبکه | ورودی | خروجی |
|---|---|---|
| سیال پایهٔ پایا | `x, y` | `u, v, p, sxx, sxy, syy` |
| تصحیح سیال گذرا | `x, y, t, x10, y10, x20, y20` | شش تصحیح میدان |
| مسیر ذرات | `t, x10, y10, x20, y20` | هشت مؤلفهٔ مسیر چهار ذره |

مختصات شرایط اولیه قبل از ورود به شبکه به `[-1,1]` تبدیل می‌شوند. سرعت و شتاب با مشتق زمانی، **در شرایط اولیهٔ ثابت**، محاسبه می‌شوند؛ مشتق نسبت به پارامترهای شرایط اولیه وارد معادلات ناویر–استوکس نمی‌شود. سیال گذرا نیز شرطی شده است تا بازخورد دوطرفهٔ درگ با همان آرایش اولیه محاسبه شود.

| مختصهٔ اولیه | بازهٔ پیشنهادی بی‌بُعد |
|---|---|
| `x10` | `[0.10, 0.18]` |
| `y10` | `[0.09, 0.20]` |
| `x20` | `[0.15, 0.24]` |
| `y20` | `[0.09, 0.20]` |

این بازه‌ها یک دامنهٔ اولیهٔ پیشنهادی برای آموزش هستند، نه دامنه‌ای که دقت شبکه در آن از قبل ثابت شده باشد. مراکز اولیه بالادست گرفتگی قرار می‌گیرند: شروع برآمدگی در `x=0.30` است. زیرمجموعهٔ مجاز این جعبه با نمونه‌برداری ردّی انتخاب می‌شود:

- فاصلهٔ هر دو مرکز باید بیشتر از `2*rp + 0.002 = 0.032` باشد.
- فاصلهٔ هر مرکز از دیواره‌ها باید بیشتر از `rp + 0.002 = 0.017` باشد.
- مراکز باید از دو صفحهٔ ابتدا و انتهای کانال نیز همین فاصله را داشته باشند.

بنابراین دو ذره می‌توانند نسبت به هم جابه‌جا یا در ترتیب افقی معکوس شوند، ولی از وضعیت هم‌پوشان شروع نمی‌کنند. درخواست ارزیابی نامعتبر به‌جای تغییر یا جابه‌جایی مصنوعی مختصات، خطا می‌دهد. برای تغییر دامنه، `config_example.json` را ویرایش و مدل را دوباره آموزش دهید؛ مدل قبلی برای دامنهٔ تازه اعتبارسنجی نشده است.

## شرایط اولیه و مدل اتصال/تماس

برای هر نمونهٔ شرایط اولیهٔ `theta`، مسیر به شکل زیر ساخته می‌شود:

```text
q(t, theta) = q0(theta) + h(t) * b(t, theta)
h(t) = t + St * (exp(-t/St) - 1)
```

در نتیجه `q(0,theta)=q0(theta)` و **`v(0,theta)=0`** دقیقاً برقرار است. این سرعت اولیه با فرمول مسیر و حل Radau کد ارسالی سازگار است. متغیر `u0` در کد قبلی سرعت واقعی در لحظهٔ صفر را تعیین نمی‌کرد، چون `h'(0)=0` بود. در نسخهٔ جدید از مقدار صفر آن استفاده شده است.

هر شش جفت ذرات همچنان اتصال **دائمی** فنر–دمپر دارند. نیروی تماس نرم نیز وقتی `distance < 2*rp` شود فعال می‌شود. این مدل چهار ذرهٔ مستقل و آزاد نیست؛ بنابراین وقوع برخورد را نمی‌توان فقط با نزدیک‌کردن مختصات اولیه تضمین کرد. هم‌پوشانی کوچک در مدل تماس نرم بخشی از فرمول نیرو است؛ از تصویر به‌تنهایی نمی‌توان صحت یا عدم برخورد را نتیجه گرفت.

دو سیاست طول تعادل در `Config.rest_lengths` وجود دارد:

- `case`، پیش‌فرض: طول تعادل هر اتصال برابر فاصلهٔ اولیهٔ همان نمونه است؛ مطابق مدل کد ارسالی، هر آرایش از تعادل فنرها شروع می‌شود. با تغییر شرایط اولیه، هندسهٔ تعادل اتصال‌ها هم تغییر می‌کند.
- `nominal`: طول تعادل از آرایش اسمی اصلی گرفته می‌شود و در تمام نمونه‌ها ثابت می‌ماند؛ تغییر موقعیت اولیه عموماً پیش‌تنیدگی ایجاد می‌کند. این یک انتخاب فیزیکی متفاوت است و به آموزش جداگانه نیاز دارد.

سیاست و شش طول تعادل در گزارش هر حالت ذخیره می‌شوند. هیچ مسیر یا موقعیت پیش‌بینی‌شده‌ای برای رفع نفوذ، برخورد یا بهتر شدن تصویر اصلاح نمی‌شود.

## نصب و اجرا

روی Python 3.12 بررسی شده است. از checkout فعلی استفاده کنید؛ برای اجرای این پروژه نیازی به Git worktree جدید نیست.

```bash
python -m venv .venv
.venv/bin/python -m pip install torch==2.9.0 --index-url https://download.pytorch.org/whl/cpu
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python stenosis_parametric_ic.py --self-test
```

برای GPU، بستهٔ PyTorch سازگار با CUDA دستگاه را از راهنمای رسمی PyTorch نصب کنید و سپس وابستگی‌های دیگر را نصب کنید. در محیط cloud حاضر، مفسر آماده در `/workspace/.venvs/spring/bin/python` قرار دارد؛ CUDA موجود نیست. در صورت نیاز، کش Matplotlib را با `MPLCONFIGDIR=/workspace/.cache/matplotlib` و کش فونت را با `XDG_CACHE_HOME=/workspace/.cache` به محل قابل نوشتن هدایت کنید.

اجرای کوتاه صرفاً برای بررسی سلامت کد:

```bash
.venv/bin/python stenosis_parametric_ic.py --quick-test --no-gif --outdir results_smoke
```

آموزش واقعی:

```bash
.venv/bin/python stenosis_parametric_ic.py --config config_example.json --outdir results_parametric
```

آموزش پارامتریک از مسئلهٔ تک‌آرایش سخت‌تر است. بودجهٔ پیش‌فرض نقطهٔ شروع است، نه تضمین همگرایی. در اجرای واقعی، اگر سیال پایه معیارهای دقت را پاس نکند، آموزش کوپل‌شده متوقف می‌شود و checkpoint ذخیره می‌شود. می‌توان با دستور زیر ادامه داد:

```bash
.venv/bin/python stenosis_parametric_ic.py --resume results_parametric/model.pt --outdir results_parametric
```

خروجی smoke را مبنای مقاله یا checkpoint شروع آموزش اصلی قرار ندهید. برچسب smoke در checkpoint و ارزیابی آن باقی می‌ماند. پوشهٔ خروجی برای اجرای تازه باید خالی باشد؛ خروجی‌های قبلی بی‌اجازه بازنویسی نمی‌شوند.

شبکهٔ زمان‌تنهای قدیمی با مدل پنج‌ورودی جدید سازگار نیست و مسیر ذرات باید دوباره آموزش ببیند. برای استفاده از **سیال پایای** checkpoint اصلی چهارذره‌ای، با هندسه و عرض/عمق شبکهٔ یکسان:

```bash
.venv/bin/python stenosis_parametric_ic.py --carrier-from path/to/old/model.pt --outdir results_transfer
```

فقط وزن‌های سیال پایه منتقل می‌شوند و پیش از ثابت‌کردن آن دوباره بررسی می‌شوند؛ شبکه‌های مسیر و سیال گذرا دوباره آموزش می‌بینند. برخلاف نسخهٔ ارسالی، آرگومان‌های خط فرمان اکنون خوانده می‌شوند؛ `parse_args(args=[])` اصلاح شده است.

## پیش‌بینی آرایش تازه با همان مدل آموزش‌دیده

برای تغییر مختصات داخل دامنهٔ آموزش، نیازی به آموزش مجدد نیست؛ دقت آن آرایش باید بررسی شود:

```bash
.venv/bin/python stenosis_parametric_ic.py \
  --evaluate results_parametric/model.pt \
  --initial 0.13 0.14 0.163 0.14 \
  --outdir results_new_case
```

چهار عدد به ترتیب `x10 y10 x20 y20` هستند. ارزیابی مجموعه‌ای از حالت‌ها:

```bash
.venv/bin/python stenosis_parametric_ic.py \
  --evaluate results_parametric/model.pt \
  --cases initial_cases.json \
  --outdir results_compare
```

آموزش پیش‌فرض در پایان ۸ حالت را جداگانه بررسی می‌کند: آرایش اسمی، آرایش نزدیک تماس، آرایش بازتر، آرایش با ترتیب افقی معکوس و نمونه‌های تصادفی با seed مستقل. هیچ میانگین‌گیری بین حالت‌ها شکست یک حالت را پنهان نمی‌کند. این تعداد حالت اثبات دقت در سراسر دامنهٔ چهاربعدی نیست.

## پیدا کردن حالت‌های محتمل تماس

پس از آموزش یک مدل معتبر:

```bash
.venv/bin/python scan_contacts.py \
  --model results_parametric/model.pt --samples 256 --outdir contact_scan
.venv/bin/python stenosis_parametric_ic.py \
  --evaluate results_parametric/model.pt \
  --cases contact_scan/selected_cases.json \
  --outdir results_selected_contacts
```

اسکن، پیش‌بینی شبکه را در شبکهٔ زمانی نمونه‌برداری می‌کند و حالت‌های نزدیک‌ترین فاصله، بیشترین هم‌پوشانی و فاصلهٔ بیشتر را انتخاب می‌کند. اسکن **اعتبارسنجی نیست**؛ حتی اگر تماس پیدا نکند، عدم تماس در زمان پیوسته را ثابت نمی‌کند. وقوع تماس باید با گزارش Radau و معیارهای دقت همان حالت تطبیق داده شود. هیچ حالت برخوردی در خروجی ساخته یا تحمیل نمی‌شود.

## خروجی‌های مناسب بررسی و تهیهٔ مقاله

برای هر حالت در `case_000/` و ...:

- `trajectory.csv`: موقعیت، سرعت و شتاب چهار ذره.
- `Radau_reference.csv`: حل مستقل معادلات ذرات، در **همان میدان سیال شبکه**؛ اعتبار مستقل CFD نیست.
- `bond_strain.csv`: کرنش هر شش اتصال.
- `contacts.csv` و `contacts.json`: فاصلهٔ مراکز، هم‌پوشانی، سرعت نسبی نرمال و سهم شتاب تماس. ستون آخر نیرو با واحد نیوتن نیست؛ مقیاس جرم و واحدهای فیزیکی لازم‌اند.
- `overview.png/.pdf`: میدان سیال، مسیر، کرنش اتصال‌ها و تاریخچهٔ آموزش؛ PDF برداری نیز ذخیره می‌شود.
- `contact_profiles.png/.pdf`: فاصله نسبت به قطر و هم‌پوشانی نسبت به قطر، همراه مسیر مستقل Radau برای فاصله‌ها.
- `motion.gif`: انیمیشن؛ `--no-gif` ساخت آن را غیرفعال می‌کند.
- `validation.json`: معیارهای دقت سیال و ذرات، طول تعادل اتصال‌ها، زمان شروع تماس‌های Radau و مقایسهٔ تشخیص تماس با PINN.

زمان تماس PINN از ۲۰۰۱ نمونهٔ زمانی گزارش می‌شود؛ رویداد شروع تماس Radau هنگام انتگرال‌گیری بررسی می‌شود. خطای اولین زمان تماس نیز در صورت تشخیص تماس توسط هر دو محاسبه می‌شود. علاوه بر معیارهای قبلی، اختلاف در تشخیص وقوع تماس باعث رد اعتبارسنجی حالت می‌شود. توافق در وقوع تماس به‌تنهایی به معنی دقت زمان تماس یا نیروی اوج نیست؛ این مقادیر برای مطالعهٔ برخورد باید جداگانه بررسی شوند.

حدود اصلی حفظ‌شده از کد شما:

| بررسی | حد پذیرش |
|---|---|
| بیشینهٔ RMS مقیاس‌شدهٔ معادلات mixed | `< 0.01` |
| RMS هر معادلهٔ مومنتوم primitive | `< 0.05` |
| خطای نسبی دبی و سرعت دیواره نسبت به U | `< 0.01` |
| RMS مقیاس‌شدهٔ معادلهٔ ذرات | `< 0.01` |
| بیشینهٔ اختلاف مؤلفهٔ موقعیت PINN/Radau تقسیم بر H | `< 0.01` |
| بیشینهٔ اختلاف مؤلفهٔ سرعت PINN/Radau تقسیم بر U | `< 0.03` |
| کمترین فاصلهٔ مراکز | `> 1.8*rp` |
| بیشترین نفوذ دیواره تقسیم بر rp | `< 0.1` |

برای استفادهٔ عددی ابتدا `passed=true` و `eligible_for_numerical_use=true` هر حالت را بررسی کنید. حتی این وضعیت، اعتبارسنجی CFD مستقل، کالیبراسیون مادهٔ فنر–دمپر یا استقلال نتیجه از پارامترهای تماس را ثابت نمی‌کند. برای مقاله، بررسی حساسیت به `pair_kn/pair_cn`، تفکیک زمانی Radau، نقاط آموزش و اندازهٔ شبکه لازم است؛ این بررسی‌ها در این تحویل اجرا نشده‌اند. تغییر ضرایب فیزیکی نیازمند آموزش جدید است، چون ورودی شبکه نیستند.

## آنچه در این تحویل آزمایش شده است

آزمون‌های نیرو/گشتاور، تعادل فنرها، نرمال‌سازی منبع گاوسی، مقایسهٔ مشتق‌ها با autograd، وجود گرادیان primitive NS، شرایط اولیهٔ دقیق پارامتریک، ۴۰۹۶ نمونهٔ مجاز، هماهنگی شرایط اولیه در انتگرال دبی، گرادیان آموزش کوپل‌شده و تماس نزدیک‌شونده/دورشونده بررسی شده‌اند. یک مسئلهٔ تماس نرم نیز با Radau مستقل حل شده است.

آموزش کوتاه دوآرایشی و بارگذاری checkpoint برای یک آرایش تازه اجرا شده‌اند. اجرای کوتاه فایل خروجی تولید کرده است ولی معیارهای دقت را پاس نکرده؛ **آموزش کامل، همگرایی مدل پارامتریک و نتایج آمادهٔ انتشار در مقاله هنوز تأیید نشده‌اند**. این تحویل، کد قابل اجرا و ابزار سنجش را فراهم می‌کند.
